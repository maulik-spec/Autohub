# AUTOHUB – Car Showcase Website

A responsive, five-page car showcase website built using **HTML5 and CSS3 only**. No JavaScript is included.

## Pages
- `index.html` – Home
- `cars.html` – Car collection
- `compare.html` – Static comparison table
- `about.html` – About the project
- `contact.html` – Contact form design

## Run the website
1. Extract the ZIP file.
2. Open the `AUTOHUB` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.
4. Keep the `css` folder in the same location as the HTML files.

## Notes
- Car photographs are loaded from Unsplash, so an internet connection is required for the remote images.
- The contact form is a front-end demonstration only. It does not send or store messages.
- Dynamic search, live filters, favourites and automatic comparison need JavaScript or a backend. The comparison table in this project is static.
- Displayed car prices/specifications are illustrative; verify current details from official manufacturers before relying on them.
